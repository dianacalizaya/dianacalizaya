## 👩‍💻 Sobre mí

¡Hola! 👋 Soy **Diana Calizaya**, una apasionada de la tecnología cloud y la inteligencia artificial. Como **Microsoft MVP en Inteligencia Artificial** 🏅, me dedico a compartir conocimiento, empoderar comunidades tech y construir soluciones innovadoras con Azure.
